# Scripts

Run with `bash <path>/sweater-vest-suede/scripts/<script> …`. Each script opens
with a comment saying what it does and how to use it; read that for details.

| Script | What it does |
| --- | --- |
| [install-optional-dependency-stub.sh](./install-optional-dependency-stub.sh) | Copies a type stub into your library so its test snippets type-check where sweater-vest is not installed. Inert wherever sweater-vest is installed. |
